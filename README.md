# ARTUR TRADE TEST — Railway Preview

Минимальный тестовый бот для запуска с телефона.

## Что увидишь
1. Бот публикует карточку «Анализ рынка» в тестовый канал.
2. Кнопка BUY/SELL заменяет фото и подпись В ЭТОМ ЖЕ посте.
3. WIN/LOSS снова обновляет тот же пост.
4. «Статистика» публикует отдельную карточку.

## Railway variables
BOT_TOKEN = токен тестового бота
ADMIN_IDS = ваш Telegram numeric ID
SIGNAL_CHANNEL_ID = @username тестового публичного канала (или -100... для приватного)
TIMEZONE = Europe/Prague

Важно: DEMO не анализирует реальный рынок и не выдаёт реальные торговые сигналы.
